# devbyfarhad — портфолио

Одностраничный сайт-портфолио без сборки: HTML, CSS и JS, плагины подключены с CDN.
Готов для GitHub Pages.

## Что внутри

- **Прелоадер:** приветствия на восьми языках, счётчик загрузки, шторка с изогнутым краем.
- **Фон из частиц** (Three.js и свои GLSL-шейдеры): 15 000 частиц на компьютере, 6 500 на телефоне. Восемь форм (сфера, узел, куб, волна, галактика, ДНК, икосаэдр, портал) перетекают одна в другую по скроллу и разлетаются от курсора.
- **Hero:** буквы выезжают по одной (SplitText). Рядом с курсором они становятся жирнее, это вариативный шрифт Roboto Flex. Роли под логотипом меняются через ScrambleText.
- **Плавный скролл** Lenis, полоса прогресса, индикатор секции, магнитные кнопки и свой курсор.
- **Работы:** горизонтальная лента с закреплением (ScrollTrigger pin), параллакс и SVG-искажение картинок. Кейс проекта открывается через GSAP Flip.
- **Инструменты:** бегущая строка разгоняется от скорости скролла, ниже «яма» с физикой Matter.js: капсулы можно хватать и бросать.
- **Процесс:** путь рисуется через DrawSVG, светящаяся точка едет по нему через MotionPath.
- **GitHub:** живые данные из API (профиль, репозитории, языки) и «терминал», который печатает команды. Ответ кешируется на час.
- **Три языка:** EN, RU и AZ, переключение со шторкой. Язык выбирается по `?lang=`, по сохранённому выбору или по языку браузера.
- **Страница 404** в том же стиле: GitHub Pages показывает её на любом несуществующем адресе.

Плагины: GSAP 3.13 (ScrollTrigger, SplitText, ScrambleText, Flip, DrawSVG, MotionPath, CustomEase), Lenis, Three.js, Matter.js.

## Что где менять

| Файл | Что внутри |
| --- | --- |
| `js/config.js` | имя, контакты (email, Telegram, LinkedIn, Instagram), проекты, капсулы навыков |
| `js/i18n.js` | все тексты интерфейса на трёх языках |
| `assets/work/` | скриншоты проектов: `*-1.jpg` обложка, `*-m.jpg` мобильная версия |
| `index.html` | `og:url`, `og:image` и `canonical`, если сайт будет не на `boss-ui24.github.io` |

Чтобы добавить проект, скопируйте объект в `projects` внутри `config.js` и положите скриншоты в `assets/work/`.

## Локальный запуск

Из этой папки:

```bash
python3 -m http.server 8000
```

Потом откройте http://localhost:8000.

## Публикация на GitHub Pages

Эта папка — отдельный git-репозиторий: ветка `main`, `origin` указывает на `github.com/boss-ui24/boss-ui24.github.io`. Репозиторий с именем `<логин>.github.io` GitHub публикует в корне домена, а проекты вроде `/SUSHI/` продолжают работать по своим адресам.

1. Создайте на GitHub **пустой публичный** репозиторий `boss-ui24.github.io`, без README, .gitignore и лицензии: https://github.com/new?name=boss-ui24.github.io&visibility=public
2. Отправьте сайт из этой папки:

   ```bash
   git push -u origin main
   ```

3. Через одну-две минуты сайт откроется по адресу https://boss-ui24.github.io/. Если нет, откройте **Settings → Pages** и выберите **Deploy from a branch → main → / (root)**.

## Как обновлять

```bash
git add -A
git commit -m "Обновил портфолио"
git push
```

GitHub пересобирает сайт сам, обычно за минуту. Если браузер показывает старую версию, обновите страницу через Cmd+Shift+R.
